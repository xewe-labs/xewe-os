xewe-os 3.0.0

xewe-os is the firmware template of XeWe OS for ESP32-C3, C6 and S3: a sketch, Config.h,
xewe.toml and two example modules. ./setup.sh installs the tools, XeWeCore, the modules and the
toolchain; `xewe` builds, flashes, provisions and tests. It is part of the XeWe OS v3 release set
(core 3.0.0, modules 3.0.0, tools 3.0.1).

3.0.0 follows 2.0.1 (2.1.0 was never tagged). Tags are X.Y.Z with no `v` from now on (v2.0.0 and
v2.0.1 keep their names).

BREAKING

- Layout. xewe.toml is the manifest (core, modules, tools, libraries; [project] version). Every
  generated file lives in build/ (never committed); src/Modules.h and run.sh are written by
  ./setup.sh. The toolchain is shared per machine in ~/.xewe-os/build-tools/.
- Refs frozen: core 3.0.0, modules 3.0.0, tools 3.0.1, ArduinoJson v7.4.3.
- The template ships no module selection (`selected = []`); a project picks its modules at first
  setup (menu, or ./setup.sh --modules LIST).
- ./run.sh erases NVS by default (--keep-nvs keeps it).

NEW

- Example modules: src/YourModule/ (the smallest complete module: a settings table, one command)
  and src/YourModuleFull/ (every xewe::Module hook, SECRET and RESTART settings, a FlexData blob,
  a pin claim, an AsyncTimer, a ListenerSet), declared in xewe-os.ino.
- Tests for them: tests/unit/test_examples.py (host) and tests/board/test_examples.py (board).
- CI (.github/workflows/ci.yml, the tools' reusable workflows at 3.0.1): build c3, c6, s3 and the
  host tests on every push; lint (`xewe format --check`, brand-lint) blocks.
- Releases: scripts/release.sh tags; CI builds c3, c6 and s3, publishes this GitHub Release and
  then commits static/firmware/releases/<version>/ to main (.bin files in Git LFS, see
  .gitattributes). The tag itself does not contain its binaries.
- Docs in doc/ (architecture.md, naming.md); agent guide in .agents/.

BINARIES

- 3.0.0-c3-xewe-os.bin, 3.0.0-c6-xewe-os.bin, 3.0.0-s3-xewe-os.bin: merged images (bootloader,
  partitions, app), written at 0x0; the template as it is, no modules selected. Also in
  firmware-3.0.0.tar.gz with manifest.json and meta.json (the resolved commits of core, modules,
  tools and ArduinoJson), and on main under static/firmware/releases/3.0.0/.

NOT VERIFIED

- The template's 13 board tests (tests/board/test_examples.py) have been compiled, never run on a
  board.
- The release job's commit to main (through Git LFS) runs for the first time on this tag.
