## 1. Release notes

```text
xewe-os 3.1.0

xewe-os is the firmware template of XeWe OS for ESP32-C3, C6 and S3: a sketch, Config.h,
xewe.toml and two sample modules. ./setup.sh installs the tools, XeWeCore, the modules and the
toolchain; `xewe` builds, flashes, provisions and tests. 3.1.0 pins the 3.1 line of the ecosystem
and ships the final form of the project Config.h, reworked samples and a leaner repository.

CHANGED SINCE 3.0.1

- Refs: core 3.1.2, tools 3.1.5 (ci.yml and xewe.toml name the same tag), modules wifi/3.1.2 (a
  module tag of the modules repo: wifi 3.1.2, the other modules 3.1.1), ArduinoJson v7.4.3.
- Config.h is a catalogue in the form of the core's doc/config.md: the core block and one block per
  selected module, each framed by bars with a start and an end line, two sections (default runtime
  values, compile time defined constants), every generated line a comment. Uncomment a #define
  line and change the value to override the default. A unit test guards the form.
- Samples: src/SimpleModule (id simple_module) prints "hello <name>" every period_s seconds, both
  values asked at first boot; src/FullModule (id full_module) shows every hook. Each has a README;
  comments in the code are one line each. Their Config.h files use the two-section form.
- Documentation: the README is an index; doc/xewe_os_ecosystem.md, doc/writing_a_module.md and
  doc/testing.md hold the text; .agents/ holds the agent docs and skills.
- static/ and .gitattributes are gone: release images are GitHub Release assets only.

BREAKING

- The sample names: YourModule is SimpleModule (XEWE_SIMPLE_MODULE_*, $simple_module),
  YourModuleFull is FullModule (XEWE_FULL_MODULE_*, $full_module). A project made from an earlier
  template owns its copies and is not affected.
- A modules ref may be a module tag (<module>/X.Y.Z) or a set tag (X.Y.Z).

IMAGES

- One merged image per chip (c3, c6, s3), written at 0x0, with its meta.json and ESP Web Tools
  manifest.json: GitHub Release assets of this release. The template as it is, no modules selected.

NOT VERIFIED

- The C6 and S3 images were compiled, not run on a board.

TESTING

What was tested, on which tree and with which result: release_card.md, generated by
scripts/release.sh --prepare 3.1.0 and attached to this release. Board tests ran on an ESP32-C3.
```
